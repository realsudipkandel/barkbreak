# Publish checklist — Bark Break

1. `node scripts/shared.test.js`
2. Load unpacked `barkbreak/`
3. Complete onboarding → allow a site
4. Open that site → dog walks in
5. Click dog → Pet / Feed / Water / Play (try combos: Fetch→Water, Pet→Boop)
6. Toolbar → collection progress, personality, hide, size, pause
7. Accept walkies once → confirm a found object appears in the popup
8. Confirm no remote network calls from the extension

Version tag for CWS update: `v` + `manifest.json` version (e.g. `v2.2.0`).

Privacy URL: `https://raw.githubusercontent.com/realsudipkandel/barkbreak/main/store/PRIVACY_POLICY.md`
